支持向量机（SVM）复习笔记

2026-09-24

基础概念

支持向量机 Support Vector Machines：找到一个最优的超平面，使得两类（后续可扩展为多类）数据间隔最大化


两条间隔线的距离 margin=2γ=2a∥ω∥margin=2\gamma=\frac{2a}{\Vert\omega\Vert}

前提一：权重向量 ω\omega 垂直于分类超平面
在分类平面中任取两个点 x1x_1 和 x2x_2

ωx1+b=0ωx2+b=0 \left\{ \begin{aligned} \omega x_1+b=0 \\ \omega x_2+b=0 \end{aligned} \right.

两式相减得到：ω(x1−x2)=0\omega(x_1-x_2)=0
其中 x1−x2x_1-x_2 与分类平面平行，所以 ω\omega 与分类平面垂直

前提二：利用支持向量构建向量关系
从 x−x^- 到 x+x^+ 的向量 x+−x−x^+-x^-，其与 ω\omega 在同方向上
即：x+=x−+2γω∣ω∣x^+=x^-+2\gamma\frac{\omega}{\vert\omega\vert}
其中 ω∣ω∣\frac{\omega}{\vert\omega\vert} 是单位向量
两边同乘 ω\omega 后加 bb，得到： ωx++b=ωx−+b+2γ∣ω∣2∣ω∣\omega x^++b=\omega x^-+b+2\gamma\frac{\vert\omega\vert^2}{\vert\omega\vert}
代入间隔线：a=−a+2γωa=-a+2\gamma\omega
即：γ=a∣ω∣\gamma=\frac{a}{\vert\omega\vert}

支持向量（Support Vectors） 即为落在隔离带上的样本点，构建出整个间隔带，其他样本点对决策边界无影响，预测时仅需存储支持向量

目标：maxω,bmargin=2γ=2a∣ω∣max_{\omega, b}margin=2\gamma=\frac{2a}{\vert\omega\vert}
约束：(ωxj+b)yj⩾a(\omega x_j+b)y_j\geqslant a

这个约束表示所有样本都必须被正确分类，且要位于隔离带之外

为了方便计算，令 a=1a=1，总间隔 2γ=2∣ω∣2\gamma=\frac{2}{\vert\omega\vert}

最大化 2∣ω∣\frac{2}{\vert\omega\vert} 即最小化 ∣ω∣\vert\omega\vert，等价于最小化 ω2\omega^2

如果无法实现完美分类呢？

软间隔（Soft Margin）

核心思想：允许犯错

目标：minω,b(ω2+C∑jξj)min_{\omega, b}(\omega^2+C\sum_{j}{\xi_j})

约束：

  • (ωxj+b)yj⩾1−ξj(\omega x_j+b)y_j\geqslant 1-\xi_j
  • ξj⩾0\xi_j\geqslant0

其中 C∑jξjC\sum_{j}{\xi_j} 是惩罚项，理解为在最大化间隔的同时，犯错越少越好
CC 越大惩罚越重，间隔越小，越容易过拟合
CC 越小惩罚越轻，间隔越大，越容易欠拟合

ξj\xi_j 为松弛变量（slack variable），表示一个样本点违反间隔边界的程度

  • 情况一：完美分类，点在隔离带外，ξj=0\xi_j=0
  • 情况二：点在隔离带内，但是分类正确，0<ξj<10<\xi_j<1
  • 情况三：彻底分类错误，ξj>1\xi_j>1

松弛变量 ξj\xi_j 本质上就是模型预测值 f(xj)f(x_j) 与真实标签 yjy_j 之间的损失
因为 f(xj)=sgn(ωxj+b)f(x_j)=sgn(\omega x_j+b)
所以 ξj=loss(f(xj),yj)=max⁡(0,1−(ωxj+b)yj)\xi_j=loss(f(x_j), y_j)=\max(0, 1-(\omega x_j+b)y_j)
称为 合页损失（Hinge Loss）

令 z=(ωxj+b)yjz=(\omega x_j+b)y_j:

  • z>1z>1 时，完全正确分类，惩罚为 0
  • 0<z<10<z<1 时，正确分类但越过分割线，给一个线性的惩罚
  • z<0z<0 时，彻底分类错误，且越偏离惩罚越重

关于SVM和逻辑回归的个人理解
逻辑回归就是输入经过 ωx+b\omega x+b 后再经过 sigmoidsigmoid 函数，根据得到的结果判断属于正还是反
svm就是经过 ωx+b\omega x+b 后判断在分类超平面的哪一侧，并不能知道概率

二分类 -> 多分类

OvA：One against all 独立训练多个SVM分类器
y=argmax⁡k(ωkx+bk)y=arg \max_k(\omega_kx+b_k) 越大，说明在这个方向跑得越远
但因为每个分类器的打分尺度不同，直接按 max 是不合理的

多分类SVM

核心思想：同时学习

目标：min⁡ω,b(∑yω(y)ω(y))\min_{\omega,b}{(\sum_y{\omega^{(y)}\omega^{(y)}})}
对所有权重向量的平方和最小化，相当于全局最大化各分类的间隔

约束：ω(yj)xj+b(yj)⩾ω(y′)xj+b(y′)+1\omega^{(y_j)}x_j+b^{(y_j)}\geqslant \omega^{(y')}x_j+b^{(y')}+1
可以理解为，正确类得分至少比错误类得分大1

类比上面的软间隔SVM，将多分类SVM扩展为 软间隔多分类SVM：

目标：min⁡ω,b(∑yω(y)ω(y)+C∑j∑y≠yjξj(y))\min_{\omega,b}{(\sum_y{\omega^{(y)}\omega^{(y)}}+C\sum_j\sum_{y\neq y_j}\xi_j^{(y)})}
对于每个错误类别 yy，都有专属松弛变量 ξj\xi_j

约束：

  • ω(yj)xj+b(yj)⩾ω(y′)xj+b(y′)+1−ξj(y)\omega^{(y_j)}x_j+b^{(y_j)}\geqslant \omega^{(y')}x_j+b^{(y')}+1-\xi_j^{(y)}
  • ξj(y)⩾0\xi_j^{(y)}\geqslant0

对于不同的 ξj\xi_j：

  • ξj=0\xi_j=0 时：完美分类，正确比错误至少高1
  • ξj>0\xi_j>0 时，错误类分太高了需要惩罚

联合优化解决了OvA方式的缺陷

优化过程

前置知识：拉格朗日乘子法
目的是将带约束的优化问题转化为无约束的优化问题

原始：
min⁡ωf(ω)\min_{\omega}{f(\omega)}
gi(ω)⩽0i=1,...,kg_i(\omega)\leqslant0\quad i=1,...,k
hi(ω)=0i=1,...,lh_i(\omega)=0\quad i=1,...,l

拉格朗日函数：
L(ω,α,β)=f(ω)+∑i=1kαigi(ω)+∑i=1lβihi(ω)\mathcal{L}(\omega,\alpha,\beta)=f(\omega)+\sum_{i=1}^{k}\alpha_i g_i(\omega)+\sum_{i=1}^{l}\beta_i h_i(\omega)
其中 αi⩾0\alpha_i\geqslant 0，这样如果满足不等式约束 gi(ω)⩽0g_i(\omega)\leqslant0，αigi(ω)\alpha_i g_i(\omega) 必定是负数（或者0），让 L\mathcal{L} 变小或不变；如果不满足不等式约束 gi(ω)⩽0g_i(\omega)\leqslant0，αi\alpha_i 可以变得无穷大，使 αigi(ω)\alpha_i g_i(\omega) 变为正无穷，让 L\mathcal{L} 变大
其中 βi\beta_i 不限制正负，因为如果满足等式约束，βihi(ω)\beta_i h_i(\omega) 一定为 00；一旦不满足，让 β\beta 和 hh 同号即可实现惩罚

引理：f(ω)如果ω满足最初限制∞如果ω不满足最初限制\max_{\alpha,\beta,\alpha_i\geqslant 0}{\mathcal{L}(\omega,\alpha,\beta)}=\left\{ \begin{aligned} f(\omega)\quad 如果 \omega 满足最初限制 \\ \infty\quad 如果 \omega 不满足最初限制 \end{aligned} \right.

  • 情况一：违反约束
    • 违反不等式约束：只需让 αi→+∞\alpha_i\rightarrow+\infty，那么 ∑i=1kαigi(ω)→+∞\sum_{i=1}^{k}\alpha_i g_i(\omega)\rightarrow+\infty，即 L→+∞\mathcal{L}\rightarrow+\infty
    • 违反等式约束：只需让 β→+∞/−∞\beta\rightarrow+\infty/-\infty，使 ∑i=1lβihi(ω)→+∞\sum_{i=1}^{l}\beta_i h_i(\omega)\rightarrow+\infty，即 L→+∞\mathcal{L}\rightarrow+\infty
  • 情况二：满足约束
    • αi=0→∑i=1kαigi(ω)=0\alpha_i=0\rightarrow \sum_{i=1}^{k}\alpha_i g_i(\omega)=0
    • hi(ω)=0→∑i=1lβihi(ω)=0h_i(\omega)=0\rightarrow \sum_{i=1}^{l}\beta_i h_i(\omega)=0


最终问题转换为： min⁡ωmax⁡α,β,αi⩾0L(ω,α,β)\min_{\omega}\max_{\alpha,\beta,\alpha_i\geqslant0}{\mathcal{L}(\omega,\alpha,\beta)}
即：通过内层的 max 调整 α,β\alpha,\beta，通过外层的 min 调整 ω\omega

原始问题：min⁡ωmax⁡α,β,αi⩾0L(ω,α,β)=p∗\min_{\omega}\max_{\alpha,\beta,\alpha_i\geqslant0}{\mathcal{L}(\omega,\alpha,\beta)}=p^*
对偶问题：max⁡α,β,αi⩾0min⁡ωL(ω,α,β)=d∗\max_{\alpha,\beta,\alpha_i\geqslant0}\min_{\omega}{\mathcal{L}(\omega,\alpha,\beta)}=d^*
弱对偶性定理：d∗⩽p∗d^*\leqslant p^* 即对偶问题最优值 ⩽\leqslant 原始问题最优值

  • 证明：
    因为 min⁡ωL(ω,α)⩽L(ω,α)\min_{\omega}\mathcal{L}(\omega,\alpha)\leqslant\mathcal{L}(\omega,\alpha)
    两边同时对 α\alpha 取最大，得：max⁡αmin⁡ωL(ω,α)⩽max⁡αL(ω,α)\max_{\alpha}\min_{\omega}\mathcal{L}(\omega,\alpha)\leqslant\max_{\alpha}\mathcal{L}(\omega,\alpha)
    既然上式对所有的 ω\omega 都成立，那对不等式右边再关于 ω\omega 取最小值也依然成立：
    max⁡αmin⁡ωL(ω,α)⩽min⁡ωmax⁡αL(ω,α)\max_{\alpha}\min_{\omega}\mathcal{L}(\omega,\alpha)\leqslant\min_{\omega}\max_{\alpha}\mathcal{L}(\omega,\alpha) 得证

强对偶性定理：如果 L(ω,α,β)\mathcal{L}(\omega,\alpha,\beta) 存在鞍点 (ω∗,α∗)(\omega^*,\alpha^*)，则在鞍点处有 d∗=p∗d^*= p^*

  • 鞍点处 对α极大值：L(ω∗,α)⩽L(ω∗,α∗)对ω极小值：L(ω,α∗)⩾L(ω∗,α∗)\left\{ \begin{aligned} 对\alpha极大值：\mathcal{L}(\omega^*,\alpha)\leqslant \mathcal{L}(\omega^*,\alpha^*) \\ 对\omega极小值：\mathcal{L}(\omega,\alpha^*)\geqslant \mathcal{L}(\omega^*,\alpha^*) \end{aligned} \right.
    maxmin 和 minmax 在鞍点处形成平衡，最终都选择 (ω∗,α∗)(\omega^*,\alpha^*)

因为SVM是凸二次规划问题，必存在鞍点（根据凸优化理论），所以强对偶性成立

KKT条件：鞍点必满足下列五个KKT条件

  • 平稳性条件：∂∂ωiL(ω,α,β)=0\frac{\partial}{\partial \omega_i} \mathcal{L}(\omega, \alpha, \beta) = 0
  • 对偶平稳性条件：∂∂βiL(ω,α,β)=0\frac{\partial}{\partial \beta_i} \mathcal{L}(\omega, \alpha, \beta) = 0 （满足等式约束）
  • 互补松弛性条件：αigi(ω)=0\alpha_i g_i(\omega) = 0
    • gi(ω)<0g_i(\omega)<0 满足约束，此时 αi=0\alpha_i=0
    • αi>0\alpha_i>0 时，gi(ω)g_i(\omega) 会为了避免惩罚使 gi(ω)=0g_i(\omega)=0
  • 原始可行性条件：gi(w)≤0g_i(w) \leq 0 （基本约束）
  • 对偶可行性条件：αi≥0\alpha_i \geq 0 （基本约束）

应用到SVM的具体实例中：

最初问题：最大化间隔 max⁡ω,b1∥ω∥\max_{\omega, b}{\frac{1}{\Vert\omega\Vert}}
所有样本必须正确分类，并在隔离带边界外：yi(ωTxi+b)≥1y_i(\omega^{T}x_i+b)\geq1

转化为拉格朗日函数的形式：

L(ω,b,α)=12ωTω−∑i=1mαi[yi(ωTxi+b)−1]\mathcal{L}(\omega,b,\alpha)=\frac{1}{2}\omega^T\omega-\sum_{i=1}^{m}\alpha_i[y_i(\omega^Tx_i+b)-1]

原始问题：min⁡ω,bmax⁡αi≥0L(ω,b,α)\min_{\omega,b}\max_{\alpha_i\geq0}\mathcal{L}(\omega,b,\alpha)

对偶问题：max⁡αi≥0min⁡ω,bL(ω,b,α)\max_{\alpha_i\geq0}\min_{\omega,b}\mathcal{L}(\omega,b,\alpha)

先在无约束条件下求 ω,b\omega,b，使偏导为 0 即可

  • 对 ω\omega 求偏导：∂∂ωL(ω,b,α)=ω−∑i=1mαiyixi=0\frac{\partial}{\partial \omega} \mathcal{L}(\omega, b, \alpha) = \omega-\sum_{i=1}^{m}{\alpha_iy_ix_i=0}

    发现：ω=∑i=1mαiyixi\omega=\sum_{i=1}^{m}{\alpha_iy_ix_i} （式1）

    其中 αi\alpha_i 是权重，yi=±1y_i=\pm1

    每次预测一个新的点 zz，先计算 ωTz+b=∑i∈SVαiyi(xiTz)+b\omega^Tz+b=\sum_{i\in SV}\alpha_iy_i(x_i^Tz)+b

    核技巧（Kernel Trick）
    在低维无法进行线性SVM时，通过升维进行线性分类

    因为样本点 xx 只以内积的形式出现，无需真的进行高维映射，只用使用核函数计算出内积，结果等于高位空间的内积即可
    核函数：在低位空间计算高维内积，K(xi,xj)=ϕ(xi)Tϕ(xj)K(x_i,x_j)=\phi(x_i)^T\phi(x_j)
    常用核函数：
    - 高斯核 K(x,z)=exp(−∥x−z∥22σ2)K(x,z)=exp(-\frac{\Vert x-z\Vert^2}{2\sigma^2})
    - 线性核K(x,z)=(xTz+c)dK(x,z)=(x^Tz+c)^d

    最优权重等于训练样本的线性组合，也就是说，只有 αi>0\alpha_i>0 的支持向量才能决定 ω\omega，大部分都是正确分类的样本 αi=0\alpha_i=0，对 ω\omega 有帮助的只有错误分类样本（SVM的稀疏性）

    预测时：y∗(z)=sign(∑i∈SVαiyiK(xi,z)+b)y^*(z)=sign(\sum_{i\in SV}{\alpha_iy_iK(x_i,z)}+b)

  • 对 bb 求偏导：∂∂βiL(ω,b,α)=∑i=1mαiyi=0\frac{\partial}{\partial \beta_i} \mathcal{L}(\omega, b,\alpha) = \sum_{i=1}^m{\alpha_iy_i}= 0 （式2）

把式1和式2代入 L(ω,b,α)\mathcal{L}(\omega,b,\alpha)：

L(ω,b,α)=∑i=1mαi−12∑i,j=1mαiαjyiyj(xiTxj)\mathcal{L}(\omega,b,\alpha)=\sum_{i=1}^{m}\alpha_i-\frac{1}{2}\sum_{i,j=1}^{m}\alpha_i\alpha_jy_iy_j(x_i^Tx_j)

即：

max⁡αJ(α)=∑i=1mαi−12∑i,j=1mαiαjyiyj(xiTxj)\max_\alpha\mathcal{J}(\alpha)=\sum_{i=1}^{m}\alpha_i-\frac{1}{2}\sum_{i,j=1}^{m}\alpha_i\alpha_jy_iy_j(x_i^Tx_j)

约束：
αi≥0∑i=1mαiyi=0\left\{ \begin{aligned} \alpha_i\geq0 \\ \sum_{i=1}^{m}\alpha_iy_i=0 \end{aligned} \right.

代入核函数：

max⁡αJ(α)=∑i=1mαi−12∑i,j=1mαiαjyiyjK(xi，xj)\max_\alpha\mathcal{J}(\alpha)=\sum_{i=1}^{m}\alpha_i-\frac{1}{2}\sum_{i,j=1}^{m}\alpha_i\alpha_jy_iy_jK(x_i，x_j)

软间隔的对偶问题推导

硬间隔的约束是 yi(ωTxi+b)≥1y_i(\omega^Tx_i+b)\geq 1。
软间隔引入了松弛变量 ξi\xi_i，约束变为：

  • yi(ωTxi+b)≥1−ξiy_i(\omega^Tx_i+b) \geq 1 - \xi_i
  • ξi≥0\xi_i \geq 0

因此，软间隔的拉格朗日函数需要引入两组乘子：αi≥0\alpha_i \geq 0（对应约束1）和 βi≥0\beta_i \geq 0（对应约束2）。

原始拉格朗日函数：

L(ω,b,ξ,α,β)=12ωTω+C∑i=1mξi−∑i=1mαi[yi(ωTxi+b)−1+ξi]−∑i=1mβiξi\mathcal{L}(\omega, b, \xi, \alpha, \beta) = \frac{1}{2}\omega^T\omega + C\sum_{i=1}^m \xi_i - \sum_{i=1}^m \alpha_i [y_i(\omega^Tx_i + b) - 1 + \xi_i] - \sum_{i=1}^m \beta_i \xi_i

原始问题：

min⁡ω,b,ξmax⁡α≥0,β≥0L\min_{\omega, b, \xi} \max_{\alpha \geq 0, \beta \geq 0} \mathcal{L}

对偶问题：

max⁡α≥0,β≥0min⁡ω,b,ξL\max_{\alpha \geq 0, \beta \geq 0} \min_{\omega, b, \xi} \mathcal{L}

对 ω,b,ξ\omega, b, \xi 求偏导并令其为 0：

  1. 对 ω\omega 求偏导：ω=∑i=1mαiyixi\omega = \sum_{i=1}^m \alpha_i y_i x_i （和硬间隔一样）
  2. 对 bb 求偏导：∑i=1mαiyi=0\sum_{i=1}^m \alpha_i y_i = 0 （和硬间隔一样）
  3. 对 ξi\xi_i 求偏导：
    C−αi−βi=0  ⟹  αi+βi=CC - \alpha_i - \beta_i = 0 \implies \alpha_i + \beta_i = C

    因为 βi≥0\beta_i \geq 0 是约束，所以得出 αi≤C\alpha_i \leq C。

最终软间隔的对偶问题：
将上述式子代回 L\mathcal{L}，ξi\xi_i 和 βi\beta_i 都会被消去，最终的优化目标与硬间隔完全一样，仅仅是约束条件多了一个上限 CC：

max⁡α∑i=1mαi−12∑i,j=1mαiαjyiyj(xiTxj)\max_\alpha \sum_{i=1}^{m}\alpha_i - \frac{1}{2}\sum_{i,j=1}^{m}\alpha_i\alpha_jy_iy_j(x_i^Tx_j)

0≤αi≤C∑i=1mαiyi=0\text{s.t.} \quad \begin{cases} 0 \leq \alpha_i \leq C \\ \sum_{i=1}^{m}\alpha_iy_i = 0 \end{cases}

强制 αi≤C\alpha_i \leq C，封顶了单个样本的最大影响力，强迫模型放弃那些极度离群的异常点

SMO序列最小优化算法：坐标上升法

每次挑两个αi,αj\alpha_i, \alpha_j，其余固定 m-2 个，问题变成一元二次函数求极值，不断循环到收敛

比如我们挑前两个，α1y1+α2y2+∑i=3mαiyi=0\alpha_1y_1+\alpha_2y_2+\sum_{i=3}^m\alpha_iy_i=0

因为 α3\alpha_3 到 αm\alpha_m 被固定了，所以后面那一串就是已知常数，记为 −ξ-\xi

等式变成 α1y1+α2y2=ξ\alpha_1y_1+\alpha_2y_2=\xi

J(α1,α2,…,αm)=J((ξ−α2y2)y1,α2,…,αm)\mathcal{J}(\alpha_1, \alpha_2, \dots, \alpha_m) = \mathcal{J}((\xi - \alpha_2 y_2)y_1, \alpha_2, \dots, \alpha_m)

约束（软间隔）：

  • 0≤α1≤C0\leq\alpha_1\leq C
  • 0≤α2≤C0\leq\alpha_2\leq C
