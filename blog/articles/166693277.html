两种基础框架

  • PAC框架
    数据理想化，假设存在完美规律，并且模型能够覆盖
    E r r o r ( h ) ≤ ε Error(h)\leq\varepsilon，绝对误差趋近于 0
  • Agnostic框架
    数据现实化，数据可能有噪声，或者规律超出了模型的能力
    假设空间 H 中表现最好的模型设为 h ∗ h^*
    要求 E r o r r ( h ) ≤ E r r o r ( h ∗ ) + ε Erorr(h)\leq Error(h^*)+\varepsilon，相对误差趋近于最优解

基本设定

已知条件

  • 样本空间 X X：所有可能出现的实例集合
  • 固定的未知分布 D D：数据按规律随机产生
  • 假设空间 H H：学习器可以用的所有模型的集合
  • 目标概念空间 C C：真实预测规律的集合

输入

训练样本集 S = ⟨ x i , c ( x i ) ⟩ S={\langle x_i, c(x_i)\rangle}

输出

学习器从假设空间 H H 中选了一个 h h 猜测真实规律 c c
怎么判断选择的 h h 好不好？
看它在同一个分布 D D 中抽取的新数据上的表现，即泛化能力

真实误差 True error


箭头所指即真实规律和我们的模型产生分歧的地方
ϵ D ( h ) ≡ P r x ∈ D [ c ( x ) ≠ h ( x ) ] \epsilon_{\mathcal{D}}(h)\equiv Pr_{x\in\mathcal{D}}[c(x)\neq h(x)]
不可计算

训练误差 Training error

判定模型在训练集上的表现
ϵ ∧ ≡ P r x ∈ S [ c ( x ) ≠ h ( x ) ] ≡ ∑ x ∈ S δ ( c ( x ) ≠ h ( x ) ) ∣ S ∣ \overset{\wedge}{\epsilon}\equiv Pr_{x\in \mathcal{S}}[c(x)\neq h(x)]\equiv\frac{\sum_{x\in \mathcal{S}}\delta(c(x)\neq h(x))}{\vert\mathcal{S}\vert}
可计算

并集引理
P ( A 1 ∪ A 2 ∪ . . . ∪ A k ) ≤ P ( A 1 ) + P ( A 2 ) + . . . + P ( A k ) P(A_1\cup A_2\cup...\cup A_k)\leq P(A_1)+P(A_2)+...+P(A_k)
多事件中至少发生一个的概率小于等于各自概率的总和

霍夫丁不等式

m 个独立同分布随机变量满足伯努利分布，P ( Z i = 1 ) = ϕ P(Z_i=1)=\phi，P ( Z i = 0 ) = 1 − ϕ P(Z_i=0)=1-\phi
实际观测概率：ϕ ∧ = ( 1 / m ) ∑ i − 1 m Z i \overset{\wedge}{\phi}=(1/m)\sum_{i-1}^mZ_i
观测值偏离真实值超过一定误差界限的概率有上界，为：

P ( ∣ ϕ − ϕ ∧ ∣ > γ ) ≤ 2 e x p ( − 2 γ 2 ) P(\vert \phi-\overset{\wedge}{\phi}\vert>\gamma)\leq2exp(-2\gamma^2)

样本量 m m 越多，犯错概率越小
γ \gamma 越大，越容易满足
γ \gamma 越小，要维持同样的概率上界，需要更多的 m m 补偿

版本空间 Version Space

  • 模型在训练集上零误差，说明模型 h h 和训练集 S S 是一致的
    C o n s i s t e n t ( h , S ) ⊨ h ( x ) = c ( x ) , ∀ ⟨ x , c ( x ) ⟩ ∈ S Consistent(h, S) \models h(x)=c(x), \forall\langle x,c(x)\rangle\in S
  • 版本空间 VS：所有能在训练集上全对的假设 h h
  • 一致学习器：在训练集上零误差的学习器
    一致学习器得到的模型一定在版本空间内

PAC 框架

目标

  • 产出假设：PAC-learner 训练后输出一个模型 h h
  • 近似正确：误差大概率趋近于 0 0
  • 大概率保证：learner 学出一个好模型的概率趋向于 1 1

核心思想：双重对冲

  • 近似性：放弃对绝对完美的追求，让误差小于 ε \varepsilon
  • 概率性：放弃对绝对保证的追求，让成功率大于 1 − δ 1-\delta

穷尽版本空间

如果 VS 中的每个模型真实误差都小于 ε \varepsilon，称为这个 VS 被 ε \varepsilon 穷尽

核心定理

假设空间 H H 有限，S S 包含 m m 个独立同分布样本，对于任意 0 ≤ ε ≤ 1 2 0\leq \varepsilon \leq \frac{1}{2} 的情况，VS 未能被 ε \varepsilon 穷尽的概率小于 ∣ H ∣ e − ϵ m \vert H\vert e^{-\epsilon m}

即候选模型越多 / 样本越少 / 误差边界越小，VS无法被穷尽的概率越高

设最大失败概率 δ \delta，则有 ∣ H ∣ e − ϵ m ≤ δ \vert H\vert e^{-\epsilon m}\leq \delta

可以得到：

  • 需要准备的样本数 m ≥ 1 ϵ ( l n ∣ H ∣ + l n ∣ 1 δ ∣ ) m\geq \frac{1}{\epsilon}(ln\vert H\vert+ln\vert \frac{1}{\delta}\vert)
  • 泛化误差 ϵ ≥ 1 m ( l n ∣ H ∣ + l n ∣ 1 δ ∣ ) \epsilon\geq \frac{1}{m}(ln\vert H\vert+ln\vert \frac{1}{\delta}\vert)
  • 真实误差 e r r o r t r u e ≤ 1 m ( l n ∣ H ∣ + l n ( 1 δ ) ) error_{true}\leq \frac{1}{m}(ln\vert H\vert+ln(\frac{1}{\delta}))

    因为泛化误差 ϵ ≥ 1 m ( l n ∣ H ∣ + l n ∣ 1 δ ∣ ) \epsilon\geq \frac{1}{m}(ln\vert H\vert+ln\vert \frac{1}{\delta}\vert) 才能使模型失败概率小于等于 δ \delta，所以 ϵ m i n = 1 m ( l n ∣ H ∣ + l n ∣ 1 δ ∣ ) \epsilon_{min}=\frac{1}{m}(ln\vert H\vert+ln\vert \frac{1}{\delta}\vert)，所以 e r r o r t r u e ≤ ϵ m i n = 1 m ( l n ∣ H ∣ + l n ( 1 δ ) ) error_{true}\leq \epsilon_{min}= \frac{1}{m}(ln\vert H\vert+ln(\frac{1}{\delta}))

总结

PAC 要求：

  • 泛化能力要求：
    • 置信大于等于 1 − δ 1-\delta
    • 误差小于 ϵ \epsilon
  • 计算效率保证：处理每一个样本的时间和所需要的样本数 m m 为多项式级别

充分条件：

  • 假设空间大小 ∣ H ∣ \vert H\vert 是 n n 的指数级
  • 处理每个样本的时间是多项式级别
  • 真实规律在假设空间中

不可知学习 Agnostic Learning

不假设真实规律在假设空间中

核心定理

  • 样本数量下界 m ≥ 1 2 ϵ 2 ( l n ∣ H ∣ + l n ∣ 1 δ ∣ ) m\geq \frac{1}{2\epsilon^2}(ln\vert H\vert+ln\vert \frac{1}{\delta}\vert)
    与 PAC 相比，精度提升一倍（ε → ε 2 \varepsilon \rightarrow \frac{\varepsilon}{2}，样本数量变为原来的 4 倍）
  • 训练误差和真实误差差距过大的概率 P r [ e r r o r D ( h ) > e r r o r S ( h ) + ε ] ≤ e − 2 m ε 2 Pr[error_D(h)>error_S(h)+\varepsilon]\leq e^{-2m\varepsilon^2}

经验风险最小化 ERM（Empirical Risk Minimization）

选定假设空间 H H，给定训练集 S S，从 H H 找出能很好拟合数据的模型 h h
泛化：对新数据用 h h 去做预测

h ∧ = a r g m i n h ∈ H ϵ ∧ S ( h ) \overset{\wedge}{h}=argmin_{h\in H}\overset{\wedge}{\epsilon}_S(h)

其中 ϵ ∧ S \overset{\wedge}{\epsilon}_S 是训练误差

误分类概率

将二分类看作伯努利分布，Z = 1 { h i ( x ) ≠ c ( x ) } Z=1\{h_i(x)\neq c(x)\}，模型犯错概率就等于伯努利变量 Z Z 取值为 1 的概率
训练误差 ϵ ∧ ( h i ) = 1 m ∑ j = 1 m Z j \overset{\wedge}{\epsilon}(h_i)=\frac{1}{m}\sum_{j=1}^mZ_j
犯错概率的上界（霍夫丁不等式）：P ( ∣ ϵ ( h i ) − ϵ ∧ ( h i ) ∣ > γ ) ≤ 2 e x p ( − 2 γ 2 m ) P(\vert \epsilon(h_i)-\overset{\wedge}{\epsilon}(h_i)\vert >\gamma)\leq2exp(-2\gamma ^2m)
所以训练误差趋近于真实误差

一致收敛

假设空间 H H 中至少存在一个训练误差和真实误差差距过大的 h h 的概率

P ( ∃ h ∈ H , ∣ ϵ ( h i ) − ϵ ∧ ( h i ) ∣ > γ ) = P ( A 1 ∪ . . . ∪ A k ) < ∑ i = 1 k P ( A i ) = ∑ i = 1 k 2 e x p ( − 2 γ 2 m ) = 2 k e x p ( − 2 γ 2 m ) P(\exist h\in H, \vert \epsilon(h_i)-\overset{\wedge}{\epsilon}(h_i)\vert>\gamma)=P(A_1\cup...\cup A_k) <\sum_{i=1}^{k}P(A_i)=\sum_{i=1}^k2exp(-2\gamma^2m)=2kexp(-2\gamma^2m)

其中 A i A_i 表示第 i 个模型出问题

一致收敛定理
所有模型表现都好的概率：

P ( ¬ ∃ h ∈ H , ∣ ϵ ( h i ) − ϵ ∧ ( h i ) ∣ > γ ) = P ( ∀ h ∈ H , ∣ ϵ ( h i ) − ϵ ∧ ( h i ) ∣ ≤ γ ) = 1 − 2 k e x p ( − 2 γ 2 m ) P(\neg \exist h\in H, \vert \epsilon(h_i)-\overset{\wedge}{\epsilon}(h_i)\vert>\gamma)=P(\forall h\in H, \vert \epsilon(h_i)-\overset{\wedge}{\epsilon}(h_i)\vert \leq\gamma)=1-2kexp(-2\gamma^2m)

设输出坏模型的概率 δ \delta，则 δ ≥ 2 k e x p ( − 2 γ 2 m ) \delta \geq 2kexp(-2\gamma^2m)（因为 δ \delta 一定要大于犯错概率的上界 P ( ∣ ϵ ( h i ) − ϵ ∧ ( h i ) ∣ > γ ) P(\vert \epsilon(h_i)-\overset{\wedge}{\epsilon}(h_i)\vert >\gamma)）

  • 样本复杂度 m ≥ 1 2 γ 2 l o g 2 k δ m\geq \frac{1}{2\gamma^2} log\frac{2k}{\delta}
    样本量只与假设空间大小 k 的对数成正比
  • 泛化误差界 γ ≥ 1 2 m l o g 2 k δ \gamma \geq \sqrt{\frac{1}{2m}log\frac{2k}{\delta}}
    所以训练误差和真实误差的差距 ∣ ϵ ∧ ( h ) − ϵ ( h ) ∣ ≤ 1 2 m l o g 2 k δ \vert \overset{\wedge}{\epsilon}(h)-\epsilon(h)\vert\leq\sqrt{\frac{1}{2m}log\frac{2k}{\delta}}

由 ϵ ( h ∧ ) ≤ ϵ ∧ ( h ∧ ) + γ ≤ ϵ ∧ ( h ∗ ∧ ) + γ ≤ ϵ ( h ∗ ∧ ) + 2 γ \epsilon(\overset{\wedge}{h})\leq\overset{\wedge}{\epsilon}(\overset{\wedge}{h})+\gamma\leq\overset{\wedge}{\epsilon}(\overset{\wedge}{h^*})+\gamma\leq\epsilon(\overset{\wedge}{h^*})+2\gamma
可知ERM得到的最优真实误差和假设空间的最优真实误差顶多差 2 γ 2\gamma

VC维（Vapnik-Chervonenkis Dimension）

用于解决假设空间 H H 大小无限的情况

打散Shatter：假设数据集 S S 有 d d 个数据，二分类有 2 d 2^d 个组合，假设空间 H H 中的模型可以得出所有可能的分类结果，就叫 H H 可以打散 S S

VC维：假设空间 H H 可以打散的最大点集的规模
不是要打散所有大小为 n 的点集，是只要存在有 n 个点的分布可以被打散即可

  • n 维空间的 m 个点，选一个当原点，m 个点能被有向超平面打散，当且仅当剩下的 m-1 个点线性无关
  • n 维空间的所有有向超平面组成的假设空间 V C = n + 1 VC=n+1

并非参数数量越多，VC维就越大
f ( x , α ) ≡ θ ( s i n ( α x ) ) f(x,\alpha)\equiv \theta(sin(\alpha x))，只有一个参数 α \alpha ，VC维等于 ∞ \infty
